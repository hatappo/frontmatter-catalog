# JSDoc


## Block tags

https://jsdoc.app/#block-tags

1. `@abstract` (synonyms: `@virtual`) This member must be implemented (or overridden) by the inheritor.
1. `@access` Specify the access level of this member (private, package-private, public, or protected).
1. `@alias` Treat a member as if it had a different name.
1. `@async` Indicate that a function is asynchronous.
1. `@augments` (synonyms: `@extends`) Indicate that a symbol inherits from, and adds to, a parent symbol.
1. `@author` Identify the author of an item.
1. `@borrows` This object uses something from another object.
1. `@class` (synonyms: `@constructor`) This function is intended to be called with the "new" keyword.
1. `@classdesc` Use the following text to describe the entire class.
1. `@constant` (synonyms: `@const`) Document an object as a constant.
1. `@constructs` This function member will be the constructor for the previous class.
1. `@copyright` Document some copyright information.
1. `@default` (synonyms: `@defaultvalue`) Document the default value.
1. `@deprecated` Document that this is no longer the preferred way.
1. `@description` (synonyms: `@desc`) Describe a symbol.
1. `@enum` Document a collection of related properties.
1. `@event` Document an event.
1. `@example` Provide an example of how to use a documented item.
1. `@exports` Identify the member that is exported by a JavaScript module.
1. `@external` (synonyms: `@host`) Identifies an external class, namespace, or module.
1. `@file` (synonyms: `@fileoverview`, `@overview`) Describe a file.
1. `@fires` (synonyms: `@emits`) Describe the events this method may fire.
1. `@function` (synonyms: `@func`, `@method`) Describe a function or method.
1. `@generator` Indicate that a function is a generator function.
1. `@global` Document a global object.
1. `@hideconstructor` Indicate that the constructor should not be displayed.
1. `@ignore` Omit a symbol from the documentation.
1. `@implements` This symbol implements an interface.
1. `@inheritdoc` Indicate that a symbol should inherit its parent's documentation.
1. `@inner` Document an inner object.
1. `@instance` Document an instance member.
1. `@interface` This symbol is an interface that others can implement.
1. `@kind` What kind of symbol is this?
1. `@lends` Document properties on an object literal as if they belonged to a symbol with a given name.
1. `@license` Identify the license that applies to this code.
1. `@listens` List the events that a symbol listens for.
1. `@member` (synonyms: `@var`) Document a member.
1. `@memberof` This symbol belongs to a parent symbol.
1. `@mixes` This object mixes in all the members from another object.
1. `@mixin` Document a mixin object.
1. `@module` Document a JavaScript module.
1. `@name` Document the name of an object.
1. `@namespace` Document a namespace object.
1. `@override` Indicate that a symbol overrides its parent.
1. `@package` This symbol is meant to be package-private.
1. `@param` (synonyms: `@arg`, `@argument`) Document the parameter to a function.
1. `@private` This symbol is meant to be private.
1. `@property` (synonyms: `@prop`) Document a property of an object.
1. `@protected` This symbol is meant to be protected.
1. `@public` This symbol is meant to be public.
1. `@readonly` This symbol is meant to be read-only.
1. `@requires` This file requires a JavaScript module.
1. `@returns` (synonyms: `@return`) Document the return value of a function.
1. `@see` Refer to some other documentation for more information.
1. `@since` When was this feature added?
1. `@static` Document a static member.
1. `@summary` A shorter version of the full description.
1. `@this` What does the 'this' keyword refer to here?
1. `@throws` (synonyms: `@exception`) Describe what errors could be thrown.
1. `@todo` Document tasks to be completed.
1. `@tutorial` Insert a link to an included tutorial file.
1. `@type` Document the type of an object.
1. `@typedef` Document a custom type.
1. `@variation` Distinguish different objects with the same name.
1. `@version` Documents the version number of an item.
1. `@yields` (synonyms: `@yield`) Document the value yielded by a generator function.

## Inline tags

https://jsdoc.app/#inline-tags

1. `@link` (synonyms: `@linkcode`, `@linkplain`) Link to another item in the documentation.
1. `@tutorial` Link to a tutorial.
